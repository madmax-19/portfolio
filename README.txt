MAD MAX — PORTFOLIO WITH CINEMATIC LOADING REVEAL

Pages included: index.html, mind-game.html, media-converter-pro.html, automatic-object-counter.html.
Shared assets: style.css, project-theme.css, script.js, water-background.html.

The main portfolio now has a custom animated MAD MAX wordmark loading screen that plays on each fresh page load, with abstract circular/triangular/organic shape transitions, violet/cyan highlights, a progress indicator, and “DESIGNED & BUILT BY YADUNAND”. The old Y/Kinetic Glass hero has been replaced by an abstract liquid-glass sculpture. Inside the content, Yadunand is shown as the creator; MAD MAX remains the site brand.

The water background uses a WebGL2 height-field ripple simulation and refractive highlights; moving the mouse or finger across the page injects ripples, and pressing creates a stronger splash. The background iframe receives pointer events through a small relay script on the main page.

Keep all files in the same folder and keep your existing assets/ folder alongside them (the assets folder was not included in the uploaded set). Open index.html in a modern browser. WebGL2 support is needed for the liquid background; the loading screen and CSS liquid sculpture have CSS fallbacks/reduced-motion handling.
