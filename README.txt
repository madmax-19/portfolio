# YADUNAND Portfolio

This is the cleaned portfolio version. The Mind Game is hosted as a separate website.

## Set the Mind Game URL
Replace `YOUR_MIND_GAME_URL` in `index.html` with the published URL of the separate Mind Game website.

Example:
`https://YOUR-GITHUB-USERNAME.github.io/YADUNAND-MIND-GAME/`
