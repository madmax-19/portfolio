PROJECT 02 / INDUSTRIAL AUTOMATION

AUTOMATIC
OBJECT COUNTER.

A portable Arduino UNO based automatic object counting system designed as a small-scale industrial automation prototype. It uses contactless ultrasonic detection, a 1.3-inch SH1106 OLED interface, a START button and audible feedback.

01 / OVERVIEW

From distance
to a useful count.

The idea

The system starts in an OFF state. Pressing START begins monitoring. When an object enters the 10 cm detection zone, the count increases and the buzzer gives a short beep. The object must move to at least 15 cm before another count can happen.

Why the 10 / 15 cm thresholds?

The two thresholds create a simple hysteresis band. This prevents the same object from being counted repeatedly when ultrasonic measurements fluctuate around the detection point.

04 / DETECTION LOGIC

Simple logic.
Reliable behavior.

IF distance ≤ 10 cm AND objectDetected = false
THEN objectCount++ → objectDetected = true → beep
ELSE IF distance ≥ 15 cm → objectDetected = false
RESULT the next object can now be counted

06 / SOURCE CODE

The Arduino
implementation. 

#include <U8g2lib.h>
#include <SPI.h>

U8G2_SH1106_128X64_NONAME_1_4W_HW_SPI oled(
  U8G2_R0, 5, 6, 7
);

#define TRIG_PIN 2
#define ECHO_PIN 3
#define START_BUTTON 4
#define BUZZER_PIN 8

const int DETECT_DISTANCE = 10;
const int RELEASE_DISTANCE = 15;

int objectCount = 0;
bool objectDetected = false;
bool systemStarted = false;

float getDistance()
{
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);

  long duration = pulseIn(ECHO_PIN, HIGH, 30000);

  if (duration == 0) return 999;

  return duration * 0.0343 / 2.0;
}

void beep()
{
  tone(BUZZER_PIN, 2000);
  delay(80);
  noTone(BUZZER_PIN);
}

void setup()
{
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
  pinMode(START_BUTTON, INPUT_PULLUP);
  pinMode(BUZZER_PIN, OUTPUT);

  digitalWrite(BUZZER_PIN, LOW);
  noTone(BUZZER_PIN);

  oled.begin();
}

void loop()
{
  if (!systemStarted)
  {
    if (digitalRead(START_BUTTON) == LOW)
    {
      delay(50);

      if (digitalRead(START_BUTTON) == LOW)
      {
        systemStarted = true;
        objectCount = 0;
        objectDetected = false;
        beep();
        delay(300);
      }
    }
    return;
  }

  float distance = getDistance();

  if (distance <= DETECT_DISTANCE)
  {
    if (!objectDetected)
    {
      objectCount++;
      objectDetected = true;
      beep();
    }
  }
  else if (distance >= RELEASE_DISTANCE)
  {
    objectDetected = false;
  }

  delay(80);
}
